# 持仓以交易记录为主（2026-11-02）

本次按用户确认替代此前强制现金约束：买入不再要求期初资金/转入，卖出继续校验历史数量。买卖不会自动启用现金账户；期初现金、转入、转出为显式现金记录，已有记录保持原样。

现金流仍参与账本重放，成本、手续费、已实现/浮动盈亏与交易日收益算法保持原样。未启用现金或任何历史步骤存在资金缺口，cash=null、cashComplete=false，总资产和证券仓位不可计算，不展示负余额或假设零余额。完整的旧现金账本仍有原余额。补录首笔交易之前的资金记录并重放可恢复完整性。独立费用、分红不自动启用现金管理。现金计算中正负累计金额仍受原数值上限约束。

首页始终突出持仓市值；标题右侧只保留记一笔。交易记录和文字更多放次级操作行；资产明细及刷新移入卡片底部。表单显示买入合计（含费用）或卖出净收入，并明确无需入金。资产明细仅在显式管理现金时展示现金；资金缺口显示记录不完整。导入预览及撤销说明同步更新。

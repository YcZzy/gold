# 持仓请求与交互优化

用户已确认：合并重复读取、短时返回复用内存快照、复用服务端核验资料、减少行情等待；首页突出资产与持仓，记账为主操作，交易记录直达，低频功能收进更多。

- 页面快照只在当前页面实例内保留，15秒内返回可复用；设置改变、读取失败、显式刷新仍读取云端。并发只读请求合并，写入后隔离旧读取，写操作保持独立、幂等和版本冲突校验。
- 证券资料优先读取服务端 instruments，有效期24小时，验证身份、类型、币种与时间；异常或过期回源。黄金采用服务端固定定义。客户端选择当前账本中已有标的无需远程核验，最终写入仍由服务端验证。
- 估值仅请求非零持仓报价，纯现金和全清仓零行情调用。备注保存使用 quoteCache，不触发行情云函数，保留缓存来源时间，过期明确标识；缺失则显示不完整。行情等待最长5秒，失败不影响已保存账本。
- 交易记录直接入口、更新状态与显式刷新、零结果可清除筛选。渲染用标的索引避免流水重复线性查找。
- 不将私密持仓写本地存储；不更改成本、现金、导入和权限规则。

验证：新增调用预算、超时降级、资料有效性、并发读取及刷新生命周期测试；运行完整Node测试并尝试本机WXML/WXSS编译。未部署前不声明线上耗时改善。

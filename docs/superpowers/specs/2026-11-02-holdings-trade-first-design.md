# 交易记录优先

用户确认：买入无需初始资金，卖出仍校验历史持仓；现金管理可选，保留已有流水；首页固定持仓市值。标题右侧仅记一笔，更多改文字移至次级行，资产明细移入卡片，保留刷新。

现金账户只由期初现金或转入转出显式启用。买卖、分红、费用仍计算现金流，但不会阻止交易。未启用或历史出现负余额时 cash=null、cashComplete=false、equity/allocation=null；有完整资金记录的旧账本结果保持不变。历史缺口可通过补录此前日期的资金记录恢复。仍校验金额范围及卖出数量。现金字段不作为收益来源。

表单展示买入合计和卖出净收入，提示无需入金。撤销、备份预览、计算说明同步文案。验证无入金买卖、费用、历史超卖、资金缺口及旧资金账本，完整测试及原生模板/样式编译。

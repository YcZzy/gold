# 持仓页统一记账入口与布局

用户在理解两个同级按钮实际共用表单后，要求优化交互及页面布局，授权实施合并「记一笔」方案。

- 顶部标题与单一「记一笔」操作。选择页展示常用买入、卖出、转入、转出；首次登记已有持仓、期初现金；其他分红、费用、拆合股按需展开。每个类型有短说明。
- 页面顺序：标题与状态 → 币种 → 资产概览 → 持仓/流水导航与次要备份入口 → 对应列表。编辑或选择类型时隐藏浏览内容，减少页面混杂。
- 从持仓卡片买卖直接进入已选标的表单。表单标题对应类型，并保留切换类型能力。返回保存本页未提交草稿；重新打开选择页可继续草稿。改记另一笔时对覆盖已有草稿明确确认。
- 返回列表保留币种、筛选和展开状态。草稿仅在当前页面内存中保留，不写入本地持久缓存。云端显式保存、修订冲突与私密显示行为保持。
- 调整概览、筛选栏和卡片间距，沿用现有纸感/黑金与紧凑模式，原生按钮保留可访问名称及展开状态。

验证：新增入口/选择/返回草稿/覆盖确认/快捷买卖测试，运行完整 Node 测试和微信原生 wcc/wcsc 编译；不将编译通过等同于真机视觉验收。

用户追加要求：整体简洁、突出核心内容。首页移除重复副标题与说明，持仓卡片默认仅保留名称代码、市值与浮动盈亏、买卖及详情入口；数量与均价移入详情，备注/加入自选也移入详情。流水隐藏修订号与同日顺序，保持原计算顺序；录入说明折叠。

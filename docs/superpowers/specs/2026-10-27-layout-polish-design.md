# 行情小程序布局与样式优化方案

日期：2026-10-27
状态：待用户确认方向

## 推荐方向

沿用纸感浅色与黑金深色，强化安静、清晰的行情阅读体验。使用现有主题变量和微信小程序原生 WXML / WXSS，不引入字体网络请求或装饰性动画。

备选一：只调整自选首页，改动最小，但其他页面仍有视觉差异。
备选二：专业紧凑行情风格，增加单屏信息量，但阅读留白减少。
推荐：统一优化所有现有页面，保持原有产品风格。

## 自选首页

保留顶部标题和添加入口，缩短副标题，保持标题与按钮垂直协调。关注列表增加「标的 / 最新价 / 涨跌幅」列标题，以一致的列宽对齐数据。给名称更多空间，价格和涨跌幅保持数字不折行，长名称允许合理换行。统一行间距、提醒标签和数据状态的字号与颜色层次。保留添加、管理、删除、拖拽排序、错误与空列表状态。

## 详情页

按照标的身份、核心报价、图表、辅助信息组织阅读顺序。核心报价最大，涨跌其次，来源与报价时间保持可读。基本行情数据使用统一网格。提醒入口采用清晰的标题和说明分组，避免长文案挤压。统一周期切换按钮，保留现有 canvas 尺寸测量与交互逻辑。

## 提醒、我的与设置页面

统一标题、正文、说明文字的字号与行距；统一卡片内外间距、圆角和分隔线。强调授权操作和开启数量，弱化辅助说明。选择器、输入框、按钮保持足够点击区域，长内容可以换行。搜索页与标的提醒编辑页沿用相同视觉规范。

## 实现边界

修改 WXML / WXSS 及必要的视觉文案，保留数据接口、授权流程、行情刷新和提醒业务逻辑。共享样式变更需要检查所有导入首页样式的页面。现有未提交修改完整保留。

## 验证

检查 WXML 结构、事件绑定和主题变量，运行现有页面回归测试。若本机可用微信开发者工具，检查窄屏与常规屏宽下的双主题、长名称、大数字、空状态、错误状态和管理模式；若不能运行真机或模拟器，明确说明视觉验证限制。

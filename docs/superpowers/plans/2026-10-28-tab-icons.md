# 底部导航图标实施计划

**目标：** 为自选、提醒、我的增加统一的线性图标，随纸感／黑金主题同步切换。

**实现：** 保留原生 tabBar；app.json 配置默认纸感图标，utils/theme.js 在已有 applyChrome 中更新三个 tab 的普通及选中图片。主题恢复、云端偏好同步复用现有调用路径。PNG 使用透明背景，72×72 像素；四种配色与现有文字颜色一致。

1. 添加主题切换验证：纸感→黑金→纸感，以及缓存恢复、云端同步，确认每个 tab 的两种图标路径有效；运行验证，确认缺失行为。
2. 在 assets/icons/tabbar 中生成折线、铃铛、用户轮廓各四种颜色的 PNG，保留可重复生成脚本。
3. 配置 app.json 的 iconPath / selectedIconPath；applyChrome 使用 wx.setTabBarItem 更新图片，兼容 API 缺失及非 tab 页面。
4. 运行 node --test tests/theme.test.js 与 node --test tests/*.test.js，检查 PNG 透明度、尺寸及 git diff。微信真机显示需开发者工具预览确认。

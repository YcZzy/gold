# 全项目按钮样式

所有 10 个页面使用 `styles/buttons.wxss`，由 `app.wxss` 导入。纸感与黑金主题继续使用现有 `--btn-*`、`--chip-*`、`--text-*` 变量。

## 使用规则

普通操作添加 `ui-btn`，并指定一种用途：

| 类名 | 用途 | 表现 |
| --- | --- | --- |
| `ui-primary` | 保存、确认、搜索、主要入口 | 实色底、主题按钮文字 |
| `ui-secondary` | 取消、重试、添加自选、分页、导出 | 透明底、细边框 |
| `ui-text` | 刷新、管理、辅助链接、清空 | 透明底、次级文字 |
| `ui-choice` | 排序、筛选、指标选项 | 紧凑轻底标签、选中时淡色强调 |
| `ui-tab` | 分类、分组、图表周期、持仓视图 | 独立于动作按钮，文字与短下划线 |
| `ui-danger` | 删除、移除、撤销 | 错误色文字 |

主按钮最小高度 72rpx、圆角 12rpx、字号 24rpx；次按钮 64rpx；辅助文字和筛选标签 56rpx。tab 单独使用 `ui-tab`（不添加 `ui-btn`），无底色、无外框，选中时显示短下划线。实际导航类容器使用分隔线，不套按钮底框。图表浏览工具等密集操作可增加 `ui-compact`。选中项添加 `ui-selected`；已有自选添加 `ui-complete`。`disabled` 保留原有业务条件，由公共样式提供禁用状态。

图标按钮使用 `ui-icon`；有可见说明文字时增加 `ui-icon-label`。可点击行情行、导航卡片和展开行使用 `ui-row`，沿用各自内容布局。所有按钮统一 `hover-class="ui-pressed"`，图标按钮保留明确的 `aria-label`。

各页面只定义按钮的宽度、位置、布局和内容，不再分别设置操作按钮的配色、圆角、字号与状态。不要在单页重新定义同类按钮的外观；共性调整放到公共文件。

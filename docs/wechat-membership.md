# 微信虚拟支付会员部署

小程序 `wx892f2174d0293f28` 使用支付应用 `1450698745`。在微信后台发布道具 `74587613`，售价设为 990 分，开启道具发货推送。每笔购买开通 30 天，会员可添加最多 30 个自选标的。

## 云开发配置

1. 准备独立的沙箱云环境。部署并运行 `initDb`，创建 `membershipOrders` 和 `membershipReceipts`。这两个集合和 `entitlements` 均设为所有客户端不可读写。为 `membershipOrders.nextCheckAt` 配置升序索引，并为订单恢复配置 `openid` 升序、`createdAt` 降序的组合索引。
2. 部署 `membership` 和 `portfolio` 云函数，选择云端安装依赖。在云开发控制台将 `membership` 的执行超时设为 30 秒。设置云函数环境变量 `WECHAT_APP_SECRET` 为小程序 AppSecret，`XPAY_ENV=1` 为沙箱，`XPAY_SANDBOX_APP_KEY` 为轮换后的沙箱 AppKey。现网单独部署到正式云环境，使用 `XPAY_ENV=0` 及轮换后的 `XPAY_PRODUCTION_APP_KEY`。
3. 上传 `membership` 云函数的定时触发器，确认控制台每 5 分钟调用 `reconcileMembership`。这是漏推送和漏发货应答的补偿入口。首日每 5 分钟查单，之后每日查单，定时补偿持续 7 天。超过 7 天的订单仍可通过微信发货通知确认。观察云函数返回的 `checked` 和 `failed`，持续失败时检查微信返回码、密钥、网络及环境配置。
4. 按微信云开发的虚拟支付推送说明，将 `xpay_goods_deliver_notify` 路由到该环境的 `membership` 云函数，使用 JSON 推送。函数通过平台签名的查单接口复核订单。客户端通过云函数调用创建和查询自己的订单。
5. 上传小程序代码并确保客户端连接到对应的云环境。iOS 正式支付还需在微信后台配置 Apple IAP。

## 联调验收

在开发者工具的沙箱环境分别验证取消支付、首次开通、提前续费和延迟到账。延迟到账时检查页面是否自动查询同一订单，离开后重新进入「我的」是否恢复待确认订单，以及权益是否在到账后更新。可用云数据库核对每一笔已支付订单是否只生成一条回执、是否只延长一次权益，以及会员到期后原有自选是否保留。

真机支付需切换到正式环境。正式验证时，检查道具价格、支付记录、发货状态和权益记录是否一致。首版涉及退款时，由运营在微信后台核对退款结果并处理会员权益。

# marketData

Display-only public quotes and raw charts for SGE Au99.99, XAU/USD, SH/SZ stocks and ETFs, BJ stocks, HK ordinary equities and ETFs (each currency counter is separate), and US NASDAQ/NYSE/Arca stocks and ETFs. No notifications are sent here.

Deploy this entire directory as the `marketData` WeChat cloud function, including `catalog.json`, both calendar files, and its local package dependencies. It has no imports from another cloud function. Initialize the server-only `instruments`, `quoteCache`, `chartCache`, and `searchCache` collections through `initDb`. Deny client access. Set the function timeout to at least 30 seconds. Quote/chart requests are limited to three seconds per route; searches and Yahoo regular quotes allow six seconds because validated cold responses exceeded three seconds. Failed chart transports can be tried sequentially. Gold and securities quote routes run concurrently. Market collections contain no user identity.

## Actions and metadata

- `search {keyword}` → `{ok, assets, source, stale?}`. Unions Eastmoney/Tencent provider matches and the full bundled BJ/HK directory, including BJ English names. An exact resolve may stop after an exact verified match. US/ETF search candidates require quote identity validation. A successful empty response differs from a failed search.
- `resolve {assetId}` → `{ok, asset}`. Gold and official BJ/HK identities resolve locally. SH/SZ identities must match exact provider results. New US symbols require exact Tencent exchange/type/currency validation. Examples: `sh510300`, `sz159915`, `bj920185`, `hk00700`, `hk80700`, `hk02800`, `usAAPL`, `usSPY`, `usBRK.B`.
- `quote {assetId}` → `{ok, asset, quote}`.
- `quotes {assetIds}` → `{ok, assets, quotes, errors}`; 1–30 IDs, with per-asset failures.
- `chart {assetId, period}` → `{ok, asset, chart}`; `intraday`, `1mo`, `3mo`, `1y`, `5y`.

Failures are `{ok:false, err, hint}`. Existing gold asset/quote shapes and fallback logic are preserved. Security assets retain `id`, `name`, `code`, `market`, `kind`, `currency`, `unit`, `precision`, `secid`, and `quoteCode`; they also expose IANA `timezone`, `exchange`, provider identities in `providers`, and calendar-dependent `supportsClose`. `kind` is `stock` or `etf`. Unknown calendar years disable close support. Canonical US quote IDs (`usBRK.B`) differ from full chart identities (`usBRK.B.N`). Only verified Eastmoney mappings are used; other US assets have a nonempty `us:SYMBOL` identity which is never inserted into an Eastmoney endpoint.

HK classification and currency come from the official complete catalog. Warrants, CBBCs, REITs, closed funds, and leveraged/inverse products are excluded. `GP-FUND` alone does not establish an ETF. US OTC suffixes are rejected. CN ETF quote metadata must say `ETF`, so a LOF cannot be accepted through a numeric code or untyped fallback.

## Providers and time

Quotes use Tencent GB18030 batches, Eastmoney per-symbol fallback where a mapping is verified, and independent Sina CN/HK fallback. CN ETF single-symbol requests can recover an interrupted batch while verifying identity. HK requests try `r_hk` then ordinary `hk`; ordinary HK quotes are always marked delayed, including when the timestamp is recent. No unauthenticated feed has an availability or real-time SLA. HK/US Tencent turnover is already in the original currency; only the legacy CN turnover mapping multiplies by 10,000. Unconfirmed volume units remain `volumeUnit:null`; HK/US quote volume is null.

US independent quote fallback uses Yahoo `meta.regularMarketPrice` and `regularMarketTime`, with exact symbol, main exchange, instrument type, USD and timezone checks. Premarket/postmarket price and fetch time are never substituted. Long-range `chartPreviousClose` is not a previous-trading-close field and is not used for that statistic. Yahoo/Nasdaq daily history is excluded because split-adjusted prices were observed. Non-sample US Eastmoney candidates are enabled only after both quote identity and raw history checks succeed; an unreachable validation source never counts as approval.

Security charts prefer generic Tencent `fqkline` with an empty adjustment token and raw `day` rows. Intraday US uses `usMinute` and the full symbol; the generic US `minute` route is rejected. The proxy/direct Tencent hosts are transport fallbacks for the same underlying source, not independent sources. Eastmoney uses `fqt=0`, with minute-K fallback for US. BJ daily history uses current-code Eastmoney, then independent Sina `bj920185`; legacy `nq835185` is never substituted. Every OHLC row is validated, including an extreme high/low ratio guard; anomalous rows fail the provider route rather than being corrected or plotted. Yahoo daily bars are not approved as strict raw-price fallback.

SH/SZ also have independent Sina raw daily and one-minute fallback routes. Historical samples match captured unadjusted prices; minute responses keep only the provider's latest actual trading date, retain full timestamps and close prices, and leave average/volume unknown. The obsolete SZ `150` split-fund prefix is excluded; current SZ ETF candidates use `159` and still require type validation.

Gold charts keep Eastmoney first, then independent SGE Au99.99 and Sina XAU routes. JSONP is parsed as data without eval. No fabricated points, timestamps, or average lines are added.

`sourceTime` is UTC epoch milliseconds derived from the provider timestamp. Tencent CN timestamps are Beijing time; HK timestamps use Hong Kong time; US timestamps use New York time with DST. US Eastmoney minute labels arrive in Beijing time and are converted with their complete date to New York before display. `sessionDate` belongs to `sourceTime`; `marketState` describes the exchange calendar at retrieval (`regular`, `auction`, `break`, `closed`, `unknown`). Daily candle labels remain exchange-local civil dates, with day-precision source timestamps at exchange-local midnight. `fetchedAt` is retrieval time. A quote older than 15 minutes is delayed, independently of whether its market is closed.

## Cache, refresh, and validation

Provider outages preserve source timestamps and set `stale:true,cached:true`. Quotes/charts older than seven days are not used as outage fallbacks. Search is fresh for five minutes and retained for one day. Search keys include the directory version and chart keys include the data-shape version, isolating old empty results and older time semantics. Instrument updates merge validated mapping/precision and earliest history evidence; production writes use a database transaction so concurrent searches and quotes cannot erase evidence. Cache writes sweep at most 100 expired rows per collection once per minute per warm runtime.

Daily charts include `coverage` with the requested and actual ranges. Verified earlier history makes a shorter response `truncated` and advances to another route. Short-history claims cannot override earlier records. A short range with insufficient evidence remains `unverified`; the UI displays the actual range and a warning. Raw per-bar volume is retained in transport data but not plotted while its units/semantics are unconfirmed.

The bundled snapshot contains all 354 BJ equities and 3,208 approved HK counters verified on 2026-10-29. Refresh from the repository root with `python3 scripts/update-market-catalog.py`. This standard-library-only script performs the BSE cookie handshake, checks complete pagination, reads the official HKEX workbook, and atomically replaces the catalog only after all validation succeeds. It retries one transport interruption, retaining normal TLS validation and refusing certificate/HTTP 4xx failures. `--fixtures tests/fixtures/markets --output /tmp/catalog.json` reproduces the captured 2026-10-28 snapshot offline. Counts may change on future complete refreshes.

Run `node --test tests/multi-market-data.test.js tests/market-data.test.js tests/read-cache.test.js`. These exercise captured full provider payloads, exact identity/type/currency rejection, DST, raw history, minute conversion, fallback, stale data, and refresh reproducibility. `createService({request, store, now})` accepts injectable transport, store, and clock; importing the module does not initialize the cloud SDK. Public APIs can fail intermittently; partial errors remain visible and deployment is a separate step.
